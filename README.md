# Aveiro
Aveiro é uma cidade muito bonito
Guia turístico de Aveiro
Este projeto tem como objetivo de apresentar a cidade de Aveiro ,destacando alguns pontos turísticos ,monumentos e gastronomia
pontos turísticos são museu de arte nova, ria de Aveiro, ponte laços de amizade, parque infante Pedro 
Os monumentos são museu de Aveiro, estátua de princesa Santa Joana, estátua de João Afonso de Aveiro
E gastronomia são caldeiradas de enguias a moda Aveiro e bacalhau de ílhavo 
Eu escolhi Aveiro porque é uma cidade muito interessante, bonito , mas tamém com muitas curiosidades
